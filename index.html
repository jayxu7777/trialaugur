How it works

01

Curate

TrialCurator, evidence agent

Uses an NCT ID to retrieve and extract evidence from ClinicalTrials.gov, PubMed, Open Targets, openFDA, prespecified web sources and company disclosures into 28 fields. A second stage standardizes or condenses eight fields and keeps the other 20 without semantic rewriting. Evidence that cannot be retrieved is recorded as missing.

02

Forecast

TrialAugur, predictor

A GPT-5 reasoning expert estimates a base rate for the development transition and updates it with the dossier evidence. An embedding expert classifies text embeddings of the evidence with TabPFN-3, using 1,800 labelled historical trials as reference examples. The rank ensemble averages the two experts' percentile ranks.

03

Adjudicate

Prespecified outcome criteria

Success requires an explicit report that the prespecified primary endpoint was met, or an explicit announcement that the next clinical phase has started. A missed primary endpoint without such an announcement, unacceptable safety or tolerability, or trial discontinuation is failure. Anything else stays unresolved.
